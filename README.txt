IKA & JAKA — NETLIFY RSVP

RSVP memakai Netlify Function + Netlify Blobs. Semua tamu mengisi online dan ucapan yang sudah masuk dapat dilihat oleh semua pengunjung.

DEPLOY:
1. Upload/deploy seluruh folder ini ke Netlify.
2. Pastikan netlify/functions/rsvp.mjs, package.json, dan netlify.toml ikut ter-upload.
3. Netlify akan memasang @netlify/blobs dan mendeploy Function.
4. Tes RSVP dari HP/browser berbeda.
